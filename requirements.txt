# This is the human-readable list of DIRECT dependencies and why each is here.
# For a reproducible install use the pinned set instead -- these bare names
# resolve ~101 packages fresh every time, which is not what you want on a
# machine exposed to the internet:
#
#     pip install -r requirements.lock.txt --extra-index-url https://download.pytorch.org/whl/cpu
#
fastapi
uvicorn[standard]
faster-whisper
numpy
httpx

# --- speech emotion recognition (server/ser.py) ---
# CPU-only torch is enough and is what we want: the GPU stays reserved for the
# LLM. On Linux/Windows install the smaller CPU wheel with
#   pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu
torch
# transformers/omegaconf/peft serve the OPT-IN MERaLiON SER backend only; the
# default emotion2vec path never imports them directly (funasr pulls transformers
# in transitively regardless, see TODO.md).
# Pinned below 5: MERaLiON-SER-v1 ships custom modelling code (trust_remote_code)
# that builds layers from torch.logspace(...).item() in __init__. transformers 5
# constructs models on the meta device, where .item() raises, so the model cannot
# load at all on v5. Revisit when the model card supports transformers 5.
transformers<5
# Required by MERaLiON's remote modelling code, which imports both at load time.
omegaconf
peft

# Required: the default emotion2vec SER backend (server/ser.py) and CAM++
# speaker id (server/speaker.py) both load through FunASR. Only the opt-in
# MERaLiON backend can do without it.
funasr
# CAM++ speaker identification (server/speaker.py) also rides on funasr, but
# needs an fbank feature backend that emotion2vec does not. kaldi-native-fbank
# is a 300 KB wheel; torchaudio also satisfies it and is much larger.
kaldi-native-fbank
# --- ASR backends beyond Whisper (server/transcriber.py) ---
# One wheel covers Parakeet TDT, Moonshine and SenseVoice (int8 ONNX, bundled
# onnxruntime). faster-whisper above stays for the whisper:* catalogue keys.
sherpa-onnx
