Speech-to-text runs on CPU. Exactly one model is resident: choosing another builds it first (downloading its files on first use), then drops the previous one. Like the interpreter switch it takes effect on the next utterance and is not persisted — a restart returns to ASR_MODEL. Whisper's cost is flat per utterance (30 s padding); Parakeet, Moonshine and SenseVoice scale with the audio.

Transcript log

Records each utterance the server handles to logs/transcripts/, one JSON line per utterance plus, with audio ticked, its WAV. Everything is off by default because the audio is other people's speech; tick only what you need. Changes apply at once and are not persisted — a restart returns to TRANSCRIPT_LOG_ENABLED / TRANSCRIPT_LOG_FIELDS. The WAV store is a rolling cap (TRANSCRIPT_LOG_MAX_AUDIO). Export for ASR scoring with python -m server.translog --export DIR.

Emotion weights

loading…
How each stage weighs in on the emotion a listener sees. Applies to the next read; not persisted, so a restart returns to the measured defaults (blend 1, every penalty 0.7). Penalties multiply the confidence score (1 = ignore that signal); the score's level picks bold, normal, or faint/"not sure". The blend is near a switch, not a smooth dial: the interpreter is almost always ~97% sure, so it decides how confident the voice must be to keep its label. Changed knobs are stamped on each transcript-log line.
